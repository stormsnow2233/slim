拾卷 2.5 使用说明
=================

安装
----
签名跟 2.4 完全一致，直接覆盖安装即可，不用先卸载。

本次改动
--------
1. 搜索结果不再是垃圾数据
   之前搜出来标题变成 list / original / jpkr、封面还是纯色方块，
   原因是用正则去扒搜索页 HTML，把页面里的前端框架英文单词当成书名抓了。
   现在改成走站点自己的 JSON 搜索接口，字段就是书名 / 地址 / 最新章节，
   出来就是干净的书目。

2. 封面按需补全
   搜索接口不返回封面，列表先用占位图显示，随后每个源在后台把前 12 本
   的封面从详情页补回来，补好一个就地刷新，不卡列表。

3. 多域名兜底
   动漫屋、漫画人、漫画BZ 各配了一个备用域名。主域名解析不到或被拦，
   会自动换另一个，成功一次的域名后面直接记住。
   状态行也会写出失败原因（连接超时 / 域名解析失败 / HTTP 4xx），
   不再只显示「连不上」。

4. 新增漫画源：漫画BZ（mangabz）
   港台译名的漫画比较全，榜单 21 部、搜索、详情、958 话目录、
   章节取图（图片带 key，解包后直连图床）都已验证通过。
   现在一共四个源：动漫屋 / 漫画人 / 漫画BZ / 拷贝漫画。

5. 移除栗子漫画源
   它的接口域名在原 App 里是云端配置下发的，换域名后这边拿不到新地址，
   一直显示连不上，先撤掉。哪天你给到它的新域名，我再接回来。

已知情况
--------
- 动漫屋和漫画人是同一套图库，同一本书两边都有，列表里会自动合并成一条。
- 拷贝漫画的搜索接口在我这边的网络被拦，没法实测，你那边能连就能用；
  连不上时状态行会写明原因。
- 漫画BZ 用的是港台译名（海賊王 / 一拳超人），跟大陆译名不一样，
  搜大陆名可能搜不到，这是源本身的命名。

其它功能（沿用 2.4）
--------------------
- 小说 / 漫画切换在左侧边栏，点顶栏菜单或从左边往右滑拉出来
- 漫画书架、整本缓存（暂停 / 继续 / 断点续传）、缓存进度与占用
- 阅读器支持上下滚动与左右翻页切换，设置里有「允许放大缩小」开关
- 底栏液态玻璃胶囊，点击有放大回弹（酷安手感）
