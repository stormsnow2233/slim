拾卷 2.12 使用说明
===================

安装
----
签名跟前几版完全一致，直接覆盖安装，不用卸载。


这版就一件事：书源可以自己加了
------------------------------

以前那十几个源是写死在代码里的，站点挂了、改版了，你只能等我出新版。

现在你自己就能加。


怎么加（最少填两个框）
----------------------

书源页 → 右上角「+」→ 填名称和网址 → 保存。

就这样。搜索、目录、正文全都走通用识别，能认多少认多少。

比如：
   名称：某某小说网
   地址：www.xxx.com

填完点「测一下能不能搜到」，输入一个关键词，会直接告诉你：
   搜到 60 本 · 813ms
   斗破之无上之境、斗破：我能固化万物天赋、斗破之苍穹……

搜不出来就往下看。


不知道搜索地址怎么填？点「自动探测」
------------------------------------

很多站的搜索框路径是 /search.php?searchkey={key} 这种，你不用记。

点「自动探测」，App 会去抓它首页，把搜索框那个 form 找出来，
自动填好方法（GET / POST）和地址。{key} 就是关键词的位置。

探测不到就说明它首页上没有搜索框（有些站搜索是走 JS 接口的），
这种源加进来也用不了搜索，先别加。


想更准？展开「解析规则」
------------------------

不填也能用，填了更准。写法是 CSS 选择器 + @字段：

   .bookbox          搜索结果里每个列表项
   h3 a@text         书名
   h3 a@href         书籍链接
   img@src           封面
   #list dd a        目录里的章节
   #content@html     正文容器

多个备选用 || 隔开，后处理用 ##正则##替换。
认不准的时候，体检会告诉你断在哪一节：列表认出来了但取不到书名，
那就说明列表选择器对了，书名那条要改。


导入别人的书源
--------------

右上角那个粘贴图标 → 把 JSON 粘进去 → 导入。

认三种：
· 单个源
· 多个源的数组 [ {...}, {...} ]
· 「阅读」App 的书源格式

「阅读」格式里的选择器（class.bookbox@tag.a@text 这种）会自动翻成 CSS，
翻不出来的字段留空，交给通用识别兜底。所以导入进来不保证百分百能用，
导入完点一下「测一下」，能不能跑一目了然。

反过来，你自己配好的源也能导出：编辑页最下面「复制这个源」，
复制出来就是 JSON，可以直接发给别人。


新增的规则
----------

一、自定义源单独一组
   排在书源页最上面「我的书源」，跟内置源一样有开关。
   点「编辑」能改，也能删。

二、新加的源默认是开着的
   加完直接在搜索里就能用，不用再去打开。

三、删掉源不影响书架
   但用这个源加的书可能就打不开了，App 会提示「这个书源已被删除或停用」，
   阅读器里点「换个源看这本」还能找回来。

四、导入不覆盖
   同一个源重复导入会按 id 更新，不会变成两条。


说实话的部分
------------
· 通用识别不是万能的。它靠的是「页面上有没有像章节链接的东西」，
  站点结构正常的能认出来，纯 JS 渲染的站（搜索结果是异步加载的）认不出来。
· 自动探测只能找首页上的 form。有些站的搜索走接口，探测不到。
· 「阅读」的规则有几百种写法，我只转了最常见的那些。
  转不对的在编辑页手动改一下选择器就行。
· 自定义源存在手机本地，卸载 App 会一起没。重要的源记得导出一份。
· 源能不能用最终还是看那个站对你的网络开不开。
  国外站被 403 的，挂代理；国内站直连被拦的，反过来。
