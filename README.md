# 拾卷（Shijuan）· 原生安卓小说阅读器

多书源聚合搜索 + 原生阅读体验。Kotlin + Jetpack Compose，无 WebView，纯原生。

## 功能

- **多书源聚合搜索**：并发请求所有启用的书源，结果按书名合并去重，同一本书有几个源可用一眼看到
- **原生阅读器**：章内左右翻页（按屏精确分页）/ 上下滚动两种模式，5 种背景色，字号行距可调，进度自动保存
- **整本导出**：详情页三点菜单可直接导出 TXT / EPUB（EPUB 带 NCX + nav 双层目录），后台跑、完成通知
- **书架**：网格布局，显示阅读进度，长按可移除
- **书源管理**：18 个内置书源，可单独开关，支持一键体检看哪个能用
- **离线缓存**：读过的章节自动缓存，断网也能接着看
- **界面**：全屏沉浸书架、右上角快捷找书、全局边缘侧栏手势、过渡动画

## 2.31 本地书籍/漫画导入与综合书架重构

- **本地多格式导入（TXT / EPUB / PDF）**：
  - 支持从手机本地存储导入电子书与漫画。
  - **TXT 导入**：自动检测编码（UTF-8、GB18030、GBK），正则智能切分卷/章，无损导入小说书架。
  - **EPUB 导入**：自动解析 container.xml / opf / ncx / nav，精准提取 XHTML 文本并将 `<img>` 标签自动转为插画标记，PagedReader 原生支持图文插画混排；纯图 EPUB 自动识别并导入漫画书架。
  - **PDF 导入**：逐页高清渲染转码，支持导入为纯图小说插画或完整漫画章节。
  - **智能类型识别与选择弹窗**：TXT 判定为小说，纯图 EPUB 判定为漫画；若无法绝对判定（如 PDF 或混合 EPUB），弹出全宽选择弹窗供用户确认「导入为小说」或「导入为漫画」。
- **全新综合书架架构**：
  - 启动默认第一页直接进入综合书架，上下分层设计：上部为「小说书架」（含最近在读与找小说快捷入口），下部为「漫画书架」（含最近在看与看漫画快捷入口）。
  - 右下角常驻高对比度「+ 导入书籍」悬浮按钮（ExtendedFloatingActionButton），随手一键导入本地书。
  - 移除原小说、漫画页面中分散重复的旧版书架 Tab，使小说与漫画专区纯粹聚焦于探索找书与分类榜单；各专区返回键平滑退回综合书架。
- **漫画体验与阅读器稳定性优化**：
  - 彻底移除漫画页冗余的源筛选标签栏（`[全部] [动漫屋 21] [漫画人 21] [漫画BZ]`），界面清爽沉浸。
  - 彻底修复漫画阅读器跨章节跳转时停留在末页的残留问题（`key(comic.url, index)` 动态重置翻页状态）。
  - 漫画章节图片加载增加 2 次静默重试机制，自愈偶发网络抖动与超时，告别手动频繁点重试。
  - 精简侧边栏（Drawer），移除与设置页重复的书源管理与网络入口。
- **全新包名规范**：严格使用 `com.storm.shijuan`。

## 2.26 核心网络引擎与正文缓存重构

- **P0 安全修复与凭据隔离**：
  - 彻底移除源码中轻小说文库（Wenku8）的硬编码账号密码与 Cookie 常量，消除共享凭据安全隐患。
  - 新增 `SecureStore` 模块，基于 Android Keystore 硬件密钥实现 AES-GCM-256 加密存储用户 Cookie 与 Host 映射。
  - 精准区分 Cloudflare 浏览器质询与普通会话失效，禁止 403 触发无谓循环重试。
- **核心网络引擎重构**：
  - **网络请求底层取消**：打通 OkHttp `Call.cancel()` 与后台线程池 `Future.cancel()`，在切源、重搜或离开页面时彻底释放网络与计算资源。
  - **单源 Deadline 预算**：多镜像、备用 URL 顺序遍历共享单源总预算（常规源 12s、SF 20s），超时提前退出，杜绝逐个镜像累加超时导致长时间卡死。
  - **三级隔离线程池**：搜索（8~16 线程）、正文加载（4~8 线程）、预取（2~3 线程，超载自动丢弃最旧任务）独立调度，避免高频任务相互挤占。
  - **Token Bucket 统一限流**：引入 `DomainRateLimiter` 令牌桶限流，替代散落无序的硬编码 `sleep`（文库8 5s / SF 800ms / 常规 150ms 平滑控制）。
  - **镜像持久化与 24h TTL**：连通镜像 `ActiveBases` 本地持久化，24 小时超期后重新探测，故障自动降级恢复。
  - **负缓存策略**：`SearchCache` 支持命中缓存 5 分钟、空结果负缓存 60 秒，网络异常不落库，防止短时间内对空源重复扫网。
  - **并发快照安全**：修复搜索结果更新未加锁快照与未切主线程刷新 UI 的问题，修复全部源被熔断过滤时反向重新运行全部源的逻辑缺陷。
- **小说目录多页翻页与正文两级缓存**：
  - **目录多页自动提取**：`TocRule` 扩充 `nextPage` 选择器与 `maxPages = 50`，支持下一页选择器与 `{page}` 模板翻页，URL 防环去重，顺序保留，无新增章节提前停止。
  - **正文两级缓存（L1+L2）**：`NovelContentCache` 建立内存 LRU（50 章）+ 磁盘文件（24h TTL，150MB 上限超额淘汰至 120MB）两级缓存体系，统一使用 `sourceId + SHA256(normalizedUrl)` 作为安全 Key，严禁错误页、403、VIP、转码失败入库。
- **书源健康管理体系升级**：
  - **历史指标统计与指数退避**：记录总请求数、成功/失败次数、搜索/目录/正文分步成功率、最近失败原因及状态码，失败熔断采用 1m/5m/30m/2h/24h 指数退避阶梯。
  - **探针机制重做**：支持 `probeKeyword`、`probeUrl` 与 `probeMode`，搜索 0 本不再误杀源站，深入抽查目录与多章节正文。
  - **界面直观展示**：书源管理卡片直观显示历史成功率与健康状态标签。
- **扩展能力与漫画优化**：
  - **自定义书源全字段 JSON 往返**：补全 `mirrors`、`nextPage`、`link`、`skip`、`volume`、`skipVolume`、`probeKeyword` 等字段无损导出导入。
  - **在线书源订阅防护**：支持 `importSubscription` 在线订阅，拦截恶意脚本注入，更新失败原子回滚。
  - **按源独立 UA 与渲染模式**：支持 `SourceRequestProfile` 与 `renderMode`（`HTTP`、`WEBVIEW`、`AUTO`）。
  - **漫画 8 秒总预算与复合去重**：多源搜索共享 8 秒总 Deadline，结果按书名 + 作者 + 路径复合 Key 去重。

## 2.18 书源修复

背着一堆「能搜到书、点进去没正文」的报障查了一遍，结论是三类完全不同的原因，分开修：

- **SF 轻小说「有目录没正文」**：源本身没坏，是目录开头十几章全是插图/人设页（`人设`、`书友画廊` 整卷都是图片），
  正文区只有一个 `<img>`，阅读器只排文字，点进去必然是空的。
  - `TocRule` 新增 `volume` / `skipVolume`：按卷标题整卷跳过（SF 跳过 `人设`、`书友画廊` 等）
  - `TocRule` 新增 `skip`：按章节名正则剔除（兜住没有卷结构的同类站点）
  - 「第一章正文过短」不再一律判死，`getChapter` 会明确报「这章是插图/图片章」
- **体检误报**：以前固定拿目录第一章试正文，正好撞上 SF 的插图章，好源被显示成 ✗。
  现在第一章不行会补测中间、四分之一处，报「目录 N 章 · 正文 M 字（换到第 k 章试的）」
- **速读谷搜不到书**：源站搜索会直接 302 到书页（单结果自动跳转），以前把落地的章节页当搜索结果，
  目录只有 6 条、正文是书籍简介。现在识别「被重定向到书页」并把书页本身当成唯一结果
- **假搜索结果**：`auto` 兜底会把站点的导航页/推荐位当成书籍列表（手机小说、bqg9 这类没有搜索入口的站）。
  现在兜底结果要求页面里真的出现搜索词，否则报「站点搜索不可用（返回的是导航/首页）」
- **起点换成 17K**：起点全站前端渲染 + 202 反爬，纯 HTTP 抓不到目录和正文（`m.qidian.com` 也只有 800 字节 JS 壳），
  这条源怎么改都是死的，删掉换成 17K（搜索 `search.17k.com/search.xhtml?c.q=`、目录 `/list/{id}.html`、正文 `.readArea div.p`）
- **目录真假判断**：章节名大量重复视为站点导航菜单而不是目录（手机小说 54 条「全部小说…」以前能混过去）
- **提示说准**：插图章 / 空页（同一章挂两条）/ 目录靠 JS 渲染 / 站点搜索不可用，四种情况各有各的文案，不再一律「正文内容过短」

- **默认书源**：默认开启改成 biqugese / sfacg / 17k / sudugu 四个实测能通的；书源开关的存储 key 升到
  `enabled_sources_v4`（书源表改过，老开关里可能还留着已下线的 `qidian`），读取时顺手过滤掉不存在的 id

实测（`.\gradlew.bat testDebugUnitTest`，本机网络）：biqugese、sudugu、17k、sfacg 四源搜索→目录→正文全通。

## 编译

需要 JDK 17 + Android SDK（compileSdk 35）。

```bash
# 修改 local.properties 里的 sdk.dir 指向你的 Android SDK
./gradlew assembleRelease
```

产物在 `app/build/outputs/apk/release/app-release.apk`。

签名配置在 `app/build.gradle.kts` 的 `signingConfigs` 中。正式发布请通过环境变量（`KEYSTORE_PATH`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`）或在 `local.properties` 中安全配置密钥库，切勿将私有证书与密码提交至公开仓库。

## 书源

书源定义在 `app/src/main/java/com/storm/shijuan/data/Sources.kt`。

规则语法（简化版「阅读」规则）：

```
".bookbox a@href"       选择器@字段（text / html / texts / 任意属性名）
".a@text || .b@text"    左失败用右
".a@text##正则##替换"    文本后处理
```

加一个源：往 `Sources.ALL` 里加一条，字段照抄最像的那个。站点结构不固定的可以直接写 `auto = true` 走通用识别。
